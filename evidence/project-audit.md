# 项目多角度检查与优化

日期：2026-10-30（Asia/Shanghai）。范围：当前本地原型的软件体验、排版、渲染、数据可靠性与内容呈现。依据为实际代码、生产构建、故障注入及桌面／手机视口检查。没有以自动化检查替代专业科学审校。

## 发现与落实

| 角度 | 发现的问题 | 本轮修改 | 验证 |
| --- | --- | --- | --- |
| 视觉与信息层级 | 首页任务、图鉴摘要和来源说明偏小、偏淡；窄桌面时间轴被压缩 | 提高正文对比与字号，调整间距、按钮尺寸，让窄屏时间轴滚动 | 桌面首页、390×844 图鉴截图；五模式无横向溢出测试 |
| 三维信息布局 | 同一画面中的物种名称互相遮挡，影响点选 | 屏幕空间避让，优先保留选中标签，缓存标签尺寸并在调整视口时刷新 | 两项布局单测；手机首页六标签无交叠测试；课堂近观检查 |
| 包体与运行性能 | 动态查图标使整套图标库进入产物；暂停、弹窗遮挡及离屏后仍不断绘制 | 显式导入实际使用的图标；统一按需渲染循环；页面隐藏与离屏暂停，交互及模型完成加载后重绘 | 构建体积；三项渲染单测；实际帧计数确认静止期间无新绘制，缩放和返回可恢复 |
| 移动端与键盘 | 收起的导航仍可被键盘访问；抽屉缺少焦点约束；筛选／换题易丢焦点 | 导航 inert、遮罩、关闭键、Escape 与焦点恢复；题型页签支持方向键／Home／End，筛选保持焦点 | 导航焦点循环、背景隔离、筛选及页签端到端测试 |
| 启动可靠性 | IndexedDB 打开或读取停滞会阻止初始化 | 打开与读取分别设置 4 秒截止时间，关闭迟到连接，失败后使用经过校验的本地备份并提示 | 两项新增存储故障测试，覆盖迟到连接与恢复后继续保存 |
| 数据保护 | 重置缺少清晰的第二次确认；隐藏导入控件不便键盘使用，大文件先读取后判断 | 重置确认页显示已有记录并提供导出，初始焦点放在取消；独立导入按钮，读取前检查文件大小 | 取消重置和键盘导入过大文件均保持原存档不变 |
| 模型加载与来源准确性 | 外部模型失败后容易留下原模型署名；失败后相同地址的缓存阻止重新加载 | 明确加载状态，15 秒超时、结构示意回退、来源随实际展品切换、重试按钮及异步取消保护；重试改变 URL 片段以避开组件失败缓存 | 故障注入后显示原创示意署名，恢复网络后重试加载 Smithsonian 扫描；原有 13 模型可见像素与署名检查全部通过 |
| 学习反馈 | 实验曲线没有明确刻度；SVG 缩小时文字难读；重置后可能保留上一轮结论 | 百分比和世代标签独立排版，图表可访问说明同步更新，重置恢复初始提示 | 桌面、手机图表检查与前进一代操作；既有实验室数值单测 |
| 可维护性 | 导航、存储、渲染逻辑混在大文件里，单独验证困难 | 提取 navigation、persistence、icons、render-loop 和 hotspot-layout 模块 | 严格 TypeScript、94 项单测与 25 项端到端测试 |
