# 课堂展景与始祖鸟调整

日期：2026-10-30。对应反馈：“建模太丑，排版还需要优化”。

本文件保留第一轮全景改版记录。后续独立近观、相机取景与资料布局调整见 inspection-refinement.md；当前构建和测试以 acceptance.md 为准。

## 本次改动

- 始祖鸟从通用球体组合改为连续身体表面，单独制作颈部、窄颌、分层翼羽、长尾羽、后肢和爪；缩小场景中的展示比例。颜色、姿态及羽毛细节仍是原创教学示意，不是经过专家审定的写实复原。
- 重新布置地面、岩石、低矮植物和后方树木，保持中央观察区域通畅；加入落地阴影与海岸水面。模型保持教学展示尺度，不表示真实共存或真实体型比例。
- Quaternius 恐龙在展景中使用非金属、哑光材质响应，保留原始颜色与纹理。其 GLB 文件和扫描展台保持原资产，材质处理在 CREDITS.md 中披露。
- 课堂弹窗改为展景与导览双栏。右侧列出六个代表生命、观察问题、选中简介、档案入口和教学操作；手机切换为上下布局和双列物种目录。
- 物种目录只聚焦相机，档案另设入口。提供复位、暂停和标签显示控制；聚焦时淡出无关标签，键盘聚焦时仍显示对应名称。
- 保持课堂学习与个人存档隔离。增加延迟分配阴影贴图的释放，避免反复打开课堂视图时遗漏 GPU 资源。

## 边界

本轮重点改进用户截图中的课堂展景，以及共享场景的植被、光照和材质。未把其余所有程序化形态替换成独立高精度模型。外部资产仍为 13 个，35 个条目仍使用程序化结构示意；没有新生成栅格资产。自动化测试与桌面浏览器截图不能证明真机 AR、帧率或科学准确性。
