# 网站细节与排版优化

日期：2026-10-30（Asia/Shanghai）。范围：现有 Vite / TypeScript 网站的排版、响应式阅读和操作反馈。

## 问题与处理

| 检查点 | 原先不足 | 本轮处理 |
| --- | --- | --- |
| 页面层次 | 正文、辅助信息与按钮字号零散，部分短屏侧栏入口靠下 | 统一阅读字号、行距、按钮高度和键盘焦点；短桌面屏幕收起侧栏装饰内容，保留导航与设置 |
| 图鉴排版 | 笔记本卡片偏窄，手机标题和收藏数挤压 | 自适应列宽；手机改为横向档案卡，收藏数独立成行；卡片底部入口对齐 |
| 筛选状态 | 组合筛选后缺少稳定的清除入口 | 增加“清除筛选”，同步清空类别、搜索与纪元，并把焦点交还搜索框 |
| 弹窗阅读 | 长档案和活动需要滚动，关闭入口容易离开视野 | 固定弹窗标题，正文单独滚动；打开弹窗时锁定背景滚动，关闭后恢复卡片焦点与页面位置 |
| 手机导航 | 收起的侧栏阴影仍可能露出边缘 | 为关闭状态补充可见性和阴影控制，保留原有焦点约束与返回行为 |
| 证据探究 | 主题卡、步骤和选项间距不一致，手机插图可能裁切 | 调整图文比例和步骤条，完整容纳主题示意图；增加解释输入字数与提示 |
| 演化实验室 | 页面较长，调参后旧结果与当前环境容易混淆 | 增加观察／环境／对照分区导航；显示当前环境，并提示参数变化后重新运行；保留上次结果和导出数据 |
| 图表与来源 | 表格、图例和来源说明的阅读层次较弱 | 增加频率轴标题，调整数据间距、表格行底色与来源正文；实线／虚线仍共同区分曲线 |
