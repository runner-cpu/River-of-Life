# Content verification report

Verification date: **2026-10-25**. Scope: `src/content/species.ts`, `src/content/chapters.ts`, `src/content/questions.ts`, `scripts/validate-species.ts` only, plus this report. No raster images generated. No commits made.

## Delivered

- 48 public Chinese exhibit records, six in each of eight chapters. Records distinguish species, genera, broader clades, and the stromatolite microbial community / sedimentary structure. Eight chapters include English exhibit subtitles and explain that their scenes combine taxa across a period rather than asserting coexistence.
- 144 questions: one definition, one distinctive fact, and one misconception per card; 18 per chapter. Answers and explanations are anchored to the exact linked card field. Every taxon has three authored, scientifically false distractors. The three questions reuse that taxon-specific distractor set; correct position rotates across all four options.
- Costs: common 20, rare 35, star 60; chapter 1 free, subsequent chapters 150. Muted natural colors.
- `speciesRecords` preserves the complete authored dataset for the release gate; `species` filters review/source-free/D-source records out of runtime. The validator checks all raw records, so filtering cannot silently permit a review record to ship.

## Scientific decisions and limits

- Eryops replaces the out-of-period Ichthyostega. Chapter 6 uses **Apatosaurus / 迷惑龙**, at the parent agent’s request to match an authentic model; it is not labelled Brontosaurus / 雷龙. Mosasaurus and Archaeopteryx retain marine and feathered diversity.
- Hyracotherium is explicitly not presented as the direct ancestor of modern horses. Its historical Chinese name is explained with the revised classification.
- Anomalocaris: the depicted genus uses a conservative approximately 34–38 cm body estimate excluding frontal appendages and tail fan, not the old unqualified one-metre reconstruction. The hard-shelled-trilobite-specialist story is treated as an outdated simplification. ROM provides anatomy; the current encyclopedia synthesis provides revised size/feeding context.
- Dunkleosteus, Helicoprion, megalodon and Paraceratherium sizes remain estimates. No precise maximum-size record is asserted. Diet/phylogenetic uncertainty is explicit for Spriggina, Charnia, Pikaia, Wiwaxia, Kimberella and Arthropleura.
- Permian extinction says 多数海洋物种, with no unsupported 96% figure. Anthropocene is explicitly not a formal geological epoch. Human populations are not ranked as evolutionary stages.
- Date bounds are approximate fossil-record / display windows, in millions of years before present; they are not exact biological origination or extinction dates. Living groups end at 0. The dodo window represents the Holocene display, not a claimed date of speciation; 1662 is a last reliable sighting convention, not a precisely known death date.
- `lengthM` supplies a representative visual scale. `sizeLabel` explicitly identifies wingspan, shoulder height, colony structure size, or body length as appropriate; these measurements should not be read as an interchangeable biological length ranking.
- Some clades begin before the chapter in which they are highlighted (e.g. mammoths, Lystrosaurus), or persist beyond it (e.g. Deinotherium). These are intentional representative era groupings and the card records retain their broader range.
- There is no claim of exhaustive primary-literature review. Most sources are clearly labelled C (Wikipedia); five ROM institutional pages add B references. Future editorial improvement can replace more C sources with institutional or primary publications without implying the present references are primary evidence.

## Source verification method

Python `urllib.request` fetched every published URL with an ordinary Mozilla user agent. HTTP 200 and the HTML page title were checked. Rendered paragraph text was parsed with the standard-library HTMLParser (not loose tag-stripping, which incorrectly captures embedded template JSON); taxon identity, anatomy, broad age and uncertainty were checked against the actual text. All 48 encyclopedia pages below and five ROM pages succeeded. Verification dates were populated only after successful fetches. No API keys were used.

Wikipedia bare URLs initially returned 403 in one probe; the explicit `?useskin=vector` URL returned the real rendered article and that exact working URL is the reference stored in content. Britannica and NHM probe URLs returned 403 and are not published sources. The accessible UCMP Dickinsonia probe was also not needed in the final reference list.

Build-time validation is intentionally offline: it validates URL syntax and verification metadata, while this report records the actual live checks. It does not guarantee that external sites will remain reachable forever.
