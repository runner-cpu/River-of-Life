# 生命长河 · 作品介绍

《生命长河》是一座在浏览器运行的生命演化史科普馆。它面向小学高年级与初中阶段的课堂试用，让学习者沿八个纪元观察生命、阅读档案、纠正误区，再把结论与证据联系起来。目标年龄与活动时长是设计假设，尚待教师和学生试测。

在线体验：[https://runner-cpu.github.io/River-of-Life/](https://runner-cpu.github.io/River-of-Life/)。浏览器直接访问，无需安装或注册。

源码仓库：[runner-cpu/River-of-Life](https://github.com/runner-cpu/River-of-Life)；详细资料见[完整项目介绍](../project-introduction.md)与[PDF](../project-introduction.pdf)。网站已于2026年10月30日上线。

## 要解决的问题

古生物科普容易停在“认出名字、记住体型”。生动的复原形象也容易被误当成全部得到证实的事实。作品因此同时呈现可交互模型、知识来源与解释任务，让学习者区分：看到了什么、资料说明什么、哪些推断仍需更多证据。

## 学习如何发生

主线包含八章、48 个生命档案和144 道卡片关联题。观察、阅读、答题和挖掘推进收藏与章节解锁，重复操作不重复奖励。进度记录表明发生过哪些操作，不直接等于知识掌握程度。

三组证据探究分别围绕始祖鸟、沧龙与提塔利克鱼展开。学习者先记录一个判断，再旋转展台或使用文字证据，对证据进行四类归类、查看关系反馈，最后解释一个新情境。结果页保留原始选择，允许用自己的话写下“观点—证据—理由”，并导出可打印记录。错误回答不会阻止完成活动，系统不把练习得分换算成“学习提升率”。

演化实验室补充“过程如何发生”的理解。对照实验从相同初始种群和随机种子出发，保持种群、突变与捕食条件一致，仅改变干旱强度，输出30 代双曲线、逐代数据和 CSV。固定种子可复现；更换种子可讨论重复结果与随机变化。这是简化教学模型，不能用于预测真实物种。

## 可交付的教学场景

教师可直接进入任意纪元，将场景投影到课堂，选择物种近观并导出学习单。证据活动无需解锁全部章节，归类/解释使用临时记录；个人成功导出满足条件可记录零点行为徽章，课堂仍隔离。手机视口可操作；完整离线准备后可在无网络场所运行核心活动，外部来源网页仍需网络，系统语音与 AR 能力取决于设备。

## 创作与技术贡献

贡献集中在学习任务组织、交互与状态管理、三维场景装配、原创结构示意、内容／模型门禁、可复现教学模型和离线运行。采用 Vite、TypeScript、Three.js 与 model-viewer；不将这些开源基础组件算作自研引擎。

13 个外部 GLB 分别使用公开许可的动画复原或馆藏扫描，保留原作者、机构、许可和处理记录；其余35 个条目使用明确标注的原创结构示意。三维资产不宣称全部自制。开发有 AI 辅助，本地导览是规则检索，未接在线大语言模型。完整披露见 AI_USAGE.md 与 CREDITS.md。

## 当前边界

三组重点探究补充了博物馆／大学来源及具体核对范围；其余内容仍需逐字段升级来源与专业审校。模型数量距原方案至少24 个合格外部模型仍有缺口。没有完成真实设备 AR 与长期性能验收，也没有实施课堂对照研究。自动化测试证明软件行为可复现，不能证明科学形态完全正确或教学有效。

## 2026-11-12 交互增强

本轮增强新增纪元与档案关系、证据四类归类及关系反馈、同主题同伴记录只读比较、逐代种群数量点阵、三组结构观察点和两枚零点行为徽章。关系图按年代组织，不代表完整系统发生关系；结构点为近似教学观察点，未做科学解剖标定。

探究解释、归类、同伴原文和实验备注只在本次窗口保留；请及时导出。独立探究JSON与个人Progress存档用途不同。Progress升级为v2并验证迁移旧记录，只持久化个人进度和徽章；课堂、演示、只读与同伴导入保持隔离。徽章只表示本机操作，不代表科学能力或学习效果。

完整操作、文件协议、存储迁移、来源范围与离线限制见[详细项目介绍](../project-introduction.md)；测试与构建身份见[交互增强证据](../../evidence/interaction-enhancement.md)。本轮增强已于2026-11-12发布，线上32个发布资源与本地构建一致，见[发布核验](../../evidence/publication-verification.json)。模型补足、真机AR、科学审校、课堂研究及正式参赛材料仍待完成。
