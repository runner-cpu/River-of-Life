## 建议主张

**《生命长河》：用三维观察和证据探究，把“认识古生物”推进到“解释为什么”。**

主目标用户暂定小学高年级与初中学习者，场景为教师引导的科学课、社团和博物馆活动。年龄适配与单次活动用时待真实试测；不宣称已经验证教学效果。

## 赛事适配修正

原设计 §14 的通用评分表和“82–92 分”属于早期内部设想，不能作为当前赛事的官方评分依据，也不能支持获奖承诺。

已核对的具体例子：2026 年中国大学生计算机设计大赛公开说明将数媒静态、数媒动漫与短片、数媒游戏与交互设计限定为“中国古代建筑成就”主题。当前生命演化题材不能直接匹配这些类别。该结论不自动延伸至该赛事其他类别，也不推断 2027 年主题。

官方核对入口（2026-10-30）：https://jsjds.blcu.edu.cn/info/1041/1974.htm 。具体报名仍需逐项确认目标届次、组别、主题、资格、原创与 AI 披露、视频／文档格式、截止时间。用户尚未指定具体赛事与届次，因此本包按可复用科普教育材料准备。

## 2026-11-12 本地交互增强

2026-11-12文档快照：线上旧基线于2026-10-30已发布，11月12日控制器复核首页HTTP 200、入口index-B7xP_END.js；本轮功能以本地acd3757为准；本说明检查时点未核验增强部署，后续部署结果以发布验证记录/Actions为准。

“纪元与档案关系”从现有章节与48档案派生年代范围，使用明确标注的压缩时间轴与等价分组列表；不是完整系统发生树，也不表示同地同时共存。小屏默认列表，可展开纪元并打开只读展台。此展台仍能旋转、缩放、查看来源、尺寸和结构标注，但不调用观察、阅读、收藏、比较记账或奖励，关闭后焦点回到原节点。完整内存Progress、updatedAt、localStorage与IndexedDB前后不变的检查已纳入回归。

本地新版探究路径为“初始判断→观察查证→四类归类→关系反馈→迁移问题→解释与记录”。每主题两张卡，可归为支持、无关、反对、需要更多信息；按钮与桌面拖放等价，全部卡片归类后显示只读SVG及等价文字列表。连线只呈现使用者对原始判断的归类，不判分、不推断能力。解释最多1200字符，返回修改可保留；关闭或刷新会丢失临时内容，应先导出。

HTML保留旧栏目并独立增加归类，旧依据单选显示“未记录”，不伪造答案或做一致性判断。JSON采用独立的`life-inquiry-record` v1协议，包含完整主题、原始与迁移选择、观察方式、卡片类别、来源及核对范围、解释；`answers.evidence`为null。它与Progress存档不是同一种文件，HTML不可当作JSON导入。

完成本人活动后，可在本地导入同一主题的完整同伴JSON，只读并列查看原始判断、归类、解释及共同来源范围，并阅读“具体差异”文本列表。不同只是记录不同，不代表谁正确。错误文件显示具体错误并保留当前内容；同伴原文按文本显示，不执行HTML，不合并本人答案，不写Progress、不授予徽章。文件选择限400000字节，解析限100000字符；验证类型、版本、完整阶段、UTC日期、选项、卡片及来源。离线可选本地文件；系统不提供上传、账号或云端同伴匹配。演示截图中的文字为讲解样例，不是真实学生或课堂研究数据。

对照实验增加四个10×10点阵，分别展示两组的初始与所选世代。取值1点数为round(频率×100)，其余为取值0；条纹1与上方耐旱表型一致。点位固定只是数量示意，不能追踪同一个体跨代生存。成功运行默认第30代，可用滑块、前后按钮和键盘选择0至30代；曲线标记、逐代表格当前行、频率和上一代百分点变化同步。第0代无上一代；更改种子、预测或环境会保留旧结果并提示重跑，重跑成功才重置世代。

始祖鸟、沧龙、提塔利克鱼各有三个默认关闭的结构观察点；其他档案显示无数据原因。扫描、复原与程序化示意使用各自的定位，沧龙动画使用随表面运动的锚点，示意点随相机投影；文字等价列表在无WebGL时仍可阅读。位置是近似教学观察点，未做科学解剖标定；看不清的扫描结构应查文字来源。第一次Esc关闭说明并回到触发点，第二次关闭展台。来源只支持具体登记范围，不认证整张卡片。

两枚新徽章只记录本机个人操作，均为零演化点，不代表科学能力。“保留判断”要求本次完成探究、至少一项“需要更多信息”归类并成功发起HTML或JSON下载；浏览器是否最终保留文件无法确认。“复现意识”要求本次活动已完成对照，再以不同种子实际运行完成，并明确为该次运行保存非空备注。仅改输入、同种子、空备注、旧运行备注不满足。备注绑定当前结果，重新运行、刷新或离开会丢失。课堂、演示、只读和同伴导入均不授予个人新徽章。

Progress数据版本升级为2，仍用localStorage键`life-museum-save-v1`与IndexedDB数据库`life-museum`、结构版本1、仓库`progress`、记录`current`。先校验v1再迁移，保留原updatedAt用于双副本择新，不追溯补发新徽章；v1中与新徽章保留ID碰巧重名的字符串不作为新奖。仅持久化徽章状态，解释、归类、同伴原文、实验备注仍为临时数据。非法导入不覆盖当前存档，拒绝未来版本；新版读取旧存档，不承诺旧网站读取v2。
