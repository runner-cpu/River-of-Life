## 建议主张

**《生命长河》：用三维观察和证据探究，把“认识古生物”推进到“解释为什么”。**

主目标用户暂定小学高年级与初中学习者，场景为教师引导的科学课、社团和博物馆活动。年龄适配与单次活动用时待真实试测；不宣称已经验证教学效果。

## 赛事适配修正

原设计 §14 的通用评分表和“82–92 分”属于早期内部设想，不能作为当前赛事的官方评分依据，也不能支持获奖承诺。

已核对的具体例子：2026 年中国大学生计算机设计大赛公开说明将数媒静态、数媒动漫与短片、数媒游戏与交互设计限定为“中国古代建筑成就”主题。当前生命演化题材不能直接匹配这些类别。该结论不自动延伸至该赛事其他类别，也不推断 2027 年主题。

官方核对入口（2026-10-30）：https://jsjds.blcu.edu.cn/info/1041/1974.htm 。具体报名仍需逐项确认目标届次、组别、主题、资格、原创与 AI 披露、视频／文档格式、截止时间。用户尚未指定具体赛事与届次，因此本包按可复用科普教育材料准备。
