## 0. v1.0 → v2.0 修订说明

v1.0 定位为"环境调控式演化沙盒"（玩家改变环境观察基因频率变化）。用户评审后明确三点反馈，构成本版全部改动：

### 0.1 致命错位（必须改，否则作品不成立）

| # | 用户反馈 | v1.0 的问题 | v2.0 修正 |
|---|---|---|---|
| **F1** | "我需要的不是调控环境控制物种演变，而是在演变过程中学习和了解更多的物种知识" | 核心循环是"干预环境→看基因漂移"，知识是副产品；没有收集感、没有知识主体地位 | 核心循环改为 **C2S 式演化之旅**：按地质年代推进，观察/学习/答题/挖掘产出"演化点"，解锁进化树与图鉴；**知识收集是主玩法** |
| **F2** | "需要真正看到 3D 建模落实到演示"（并点名《一湖之年》3D 交互差、建模没用上） | v1.0 全程 2D 俯视程序化图形；《一湖之年》的教训：3D 若不是核心体验就会沦为背景板 | 全面转向 **Three.js 3D**：主线为可交互 3D 生态场景，图鉴每物种必有 3D 可旋转模型台；新增 §7"3D 体验红线"与里程碑 3D 验收项，制度性防止重蹈覆辙 |
| **F3** | "像从细胞到奇点那样，有图鉴和各种模式，能够吸引人" | v1.0 对标的是"科学仪器"（PhET 式），冷；模式单一 | 对标《从细胞到奇点》：**五种模式**（演化之旅 / 物种图鉴 / 化石挖掘 / 知识挑战 / 演化实验室）+ 演示模式 + AR 展示 |

### 0.2 保留的资产

- v1.0 的个体演化模拟引擎设计（§8 演化实验室）**降级为第五模式**，M3 实现——它为"技术实现"评分提供深度（ABM、确定性、能量审计），也是与 C2S 拉开差异的技术底牌
- 参数分级 A/B/C/D、来源门禁、确定性回放、里程碑验收制、AI 使用记录等工程纪律全部保留，迁移到**知识内容管理**上（每个物种卡必须带可访问来源，无来源不渲染——本草宇宙已验证的 `validate:data` 模式）

## 1. 定位与边界

### 1.1 核心主张

> **游戏里每一点进度，都来自一次真实的学习——你越是了解生命，生命史就为你展开得越多。**

四重一致性：

1. **机制核心**：演化点的全部来源都是学习行为（观察生物、阅读知识卡、答对题目、挖出化石、完成章节任务）——没有纯点击挂机产出，学习动作即游戏动作
2. **科学事实**：内容按地质年代与演化谱系组织，知识卡带分级来源
3. **玩家带走的话**："为了看霸王龙，我顺手学了一堆寒武纪知识。"
4. **答辩第一句**："我们把'学习行为'做成了游戏的核心循环，而不是把知识贴在游戏上。"

### 1.2 是什么

- **3D 生命演化史科普馆**：从 38 亿年前的细胞到人类，按地质年代分 8 章，每章一个可交互 3D 生态场景
- **收集型图鉴**：48+ 物种，每个物种 = 3D 展示台（旋转/缩放/动画/体型对比/AR 投放）+ 带来源的知识卡 + 语音讲解
- **多模式**：五种模式（演化之旅 / 物种图鉴 / 化石挖掘 / 知识挑战 / 演化实验室），外加一键演示与 AR 展示
- **低门槛**：浏览器打开即玩，无注册；移动端适配；首次 3 分钟内解锁第一个物种

### 1.3 不是什么

- 不是严格的演化模拟器为主线（模拟在第五模式里，进阶玩法）
- 不是纯点击放置游戏（没有无意义的点击产出，进度全部由学习行为驱动）
- 不是博物馆官网复刻（有游戏性：收集、解锁、挖掘、挑战）
- 不是 VR 专用作品（Web 3D 为主，AR 是增强能力，非准入条件）
- 不宣称复原形象为学术定论（古生物复原天然存在争议与更新）

### 1.4 与《一湖之年》的差异（避免"实质相同"审查）

| 维度 | 《一湖之年》 | 《生命长河》 |
|---|---|---|
| 类型 | 生态治理决策推演（策略） | 演化史科普收集（科普馆/数字展陈） |
| 核心循环 | 定政策→看结算 | 学习→解锁→收集→再学习 |
| 时间观 | 1–10 年的未来推演 | 38 亿年的历史回溯 |
| 3D 地位 | 水面/滩涂呈现（背景级） | 场景+模型台+AR，3D 即核心体验 |
| 知识载体 | 因果解释报告 | 48+ 物种图鉴 + 章节任务 + 问答 |

## 2. 竞品分析

| 竞品 | 是什么 | 学什么 | 差异化 |
|---|---|---|---|
| 《从细胞到奇点：进化永无止境》（用户指定参考） | 放置式演化之旅：点击产出进化点，解锁**预设进化树**，图鉴+章节+点击小事件 | 章节制年代叙事、进化树作为总进度结构、图鉴体系、"一次一条知识"的低认知负荷、随手可停的碎片化节奏 | ①**进度来源不同**：它靠点击（认知含量≈0），我们每个点都来自学习动作；②**模型级 3D 展示台+AR**（它是场景动画为主）；③**来源门禁**（每张卡可查证）；④第五模式演化实验室提供它没有的"活"演化 |
| 北京自然博物馆"生命长河"等实体展陈 | 沉浸式标本大厅 | 章节动线、体型对比的震撼、标本式庄重感 | 线上化+可交互+游戏化+移动端 AR |
| Google Arts & Culture / Smithsonian 3D 数字馆藏 | 高质量 3D 扫描开放数据 | **直接使用其 CC0 模型作为内容源**（见 §6.3） | 它们是"看"，我们是"玩+学+收集" |
| Spore / 物种创造器类 | 捏生物 | 视觉化生命史诗的吸引力 | 不做创造，做"认识真实存在的生命" |
| 拍拍识物/识花类 App | 拍照识别 | 即时反馈的知识获取 | 我们有叙事线与收集闭环 |

**差异化总结（答辩用）**：把《从细胞到奇点》的进度结构、自然博物馆的藏品质量（开放获取 3D 扫描）、可验证的知识来源管理、以及一个真正在跑的演化模拟引擎，装进同一个浏览器作品。

## 4. 五种模式

### 4.1 演化之旅（主线，8 章）

按地质年代推进。每章 = 一个 3D 生态场景 + 章节任务链 + 该年代物种解锁 + 一个"大事件"（大爆发/大灭绝转场）。

```
进入章节 → 3D 场景自由观察（旋转/缩放/点击生物热点）
   ↓ 点击生物 = 观察（+演化点）→ "加入图鉴"
完成章节任务（观察 N 种 / 答对 M 题 / 挖掘 K 块化石 / 看体型对比）
   ↓
大事件转场（寒武纪大爆发 / 二叠纪大灭绝 / K-Pg 陨石……视觉高潮）
   ↓
解锁下一纪元 + 章节观测结论（一句话带走）
```

### 4.2 物种图鉴（收集核心）

每个物种条目：

- **3D 展示台**：`<model-viewer>` 集成——旋转、缩放、播放动画、自动展台旋转；**AR 按钮**（Android Scene Viewer / iOS Quick Look）：把霸王龙放进教室
- **体型对比**：与人类剪影/手掌的比例尺可视化（科普冲击力担当）
- **知识卡**：定义、年代、分类、食性、栖息地、大小、发现地、趣闻、灭绝原因（如已灭绝）——每字段带来源与分级
- **语音讲解**：Web Speech API TTS 中文朗读（零成本）
- 收集激励：图鉴完成度百分比、章节徽章、稀有度分层（常见/稀世/明星物种）

### 4.3 化石挖掘（小游戏，吸引力的钩子）

刮擦式交互：屏幕覆盖岩层，手指/鼠标刮开 → 逐渐露出化石轮廓（物种剪影）→ 完全刮出后播放"复原动画"（化石 → 覆上血肉 → 3D 模型登场）→ 解锁图鉴。挖掘场按章节开放。成本极低（Canvas 遮罩 + 模型入场动画），是演示视频的高光素材与儿童吸引点。

### 4.4 知识挑战

- **快问快答**：题库 100+ 题，全部锚定图鉴知识卡（答错即时展示卡面纠错——错题即学习）
- **时间轴排序**：把 5 个物种按出现年代排序（演化学核心素养：深时概念）
- **匹配连线**：物种↔年代/食性/分类
- 每日一挑战（本地生成，seed 固定，可分享成绩码）

### 4.5 演化实验室（第五模式，v1.0 资产降级版）

微观演化沙盒（2D，完整保留 v1.0 §6 的基因/选择/漂变/捕食模型与结构验证断言，UI 精简）。定位与话术：*"图鉴告诉你演化 resulted in 什么，实验室让你看见演化 how 发生。"* 入口放在图鉴每个物种卡的"在实验室观察它的适应策略"按钮——与主线打通（在实验室成功让耐旱基因上升，回主线领取徽章）。M3 实现，砍掉也不影响主线完整。

### 4.6 演示模式（继承姊妹项目经验）

首屏「▶ 90 秒看懂这个作品」：寒武纪海底场景 → 点击三叶虫观察 → 图鉴 3D 展示台 → 挖掘化石 → 奇虾登场 → 大爆发转场 → 手机 AR 把模型放在桌上。全程无交互可接管。

## 6. 内容体系（框架完整性的核心）

### 6.1 物种数据库（完整 schema 见附录 C）

`species.json` 每条目：标识、中文名/拉丁名、分类树（界门纲目科属种）、年代区间、体型数据（长/高/重）、食性、栖息地、灭绝时间与原因、知识卡字段组（定义/趣闻/误区）、模型字段（url/scale/动画列表/面数/许可）、来源字段（url+级别+核对日期）、解锁条件、稀有度。

### 6.2 内容管线与门禁（本草宇宙 validate:data 模式直接迁移）

```
策划选题 → 资料核实（每个断言找来源，A/B/C 分级）→ 模型获取（许可核查）
   → 模型处理（gltf-transform：Draco 压缩、贴图降采样、面数上限 20k、尺寸 < 2MB）
   → 登记 species.json → `npm run validate:species` 门禁：
       · 必填字段齐全
       · 来源 URL 为 https 且登记核对日期
       · 模型存在且过预算（面数/体积/含动画或标记 static）
       · 无来源 → status='review' → 图鉴不渲染（与本草宇宙民族对照同规则）
```

**这条门禁是"内容可信"支柱的执行机构，也是答辩时"资料可信"的直接证据**（用户在本草宇宙已验证该模式有效）。

### 6.3 3D 模型来源策略（不自己建模，用开放数据）

| 来源 | 内容 | 许可 | 用途 |
|---|---|---|---|
| **Smithsonian Open Access 3D**（3d.si.edu） | 化石/骨架博物馆级扫描（霸王龙、猛犸象等） | CC0 | 图鉴明星物种的"真品"展示——**"博物馆级模型"是本作最硬的内容差异点** |
| **Sketchfab**（按 CC0/CC-BY 过滤） | 大量带动画的古生物复原模型 | 逐个核查 | 场景内活性生物 |
| **Poly Pizza / Quaternius** | 低多边形风格化动物/恐龙包，多含动画 | CC0 为主 | 场景配角与填量 |
| **Mixamo**（人形） | 类人角色动画 | 免费（遵守 Adobe 条款） | 第 8 章人类演化 |
| 自制（最后兜底） | 寒武纪奇特生物等无现成模型者 | — | **只允许占位不超过总量 25%**，且风格统一为低多边形 |

管线纪律：每个模型登记来源+许可+处理参数，记入 `CREDITS.md`（竞赛知识产权条款硬要求）。

### 6.4 知识卡来源分级（继承姊妹项目 A/B/C/D 体系）

| 级别 | 来源 | 要求 |
|---|---|---|
| A | 同行评议论文/教科书 | URL+页码或 DOI |
| B | 博物馆/科研机构公开页（Smithsonian、中科院古脊椎所 IVPP、自然博物馆官网） | URL |
| C | 权威科普媒体/百科 | URL+核对日期 |
| D | 待核实 | 显式标注，参赛模式构建告警 |

## 7. 3D 体验红线（直接回应《一湖之年》的教训）

《一湖之年》的失败模式：3D 做了，但交互浅（没有可玩的对象）、模型少（没被用起来）、沦为曲线图表的背景板。本作以下五条为**验收红线**，每个里程碑逐条过：

| # | 红线 | 验收方式 |
|---|---|---|
| R1 | 图鉴**每个**物种必有 3D 可旋转展示台（或明确标注"复原图卡"并给出理由） | 图鉴遍历脚本 + 录屏 |
| R2 | 主线每个场景至少 **3 个可点击生物热点**（点击→聚焦动画→信息浮层→入图鉴） | E2E 测试断言 |
| R3 | 场景内生物**有动画**（游动/走动/进食 idle 循环），不允许静帧贴片 | 录屏验收 |
| R4 | 每个 3D 对象可被相机围绕观察（轨道交互不被锁死），移动端手势可用 | 手动+Playwright 触控模拟 |
| R5 | **AR 投放**可用（Android/iOS 至少一端真机录屏） | 真机验收 |

交互标准件（全作复用）：轨道相机（惯性阻尼）、点击热点（高亮描边+聚焦推镜）、信息浮层（半屏抽屉）、体型对比尺、AR 按钮。**每个里程碑的验收清单里必须有 3D 录屏项**——不是"做完 3D"，是"3D 被玩到了"。

## 10. 技术架构

### 10.1 选型

| 项 | 选择 | 理由 |
|---|---|---|
| 构建 | Vite 5 + TypeScript 5（strict） | 与既有项目工具链一致 |
| 3D 场景 | **Three.js**（esbuild 自托管，本草宇宙先例） | 用户已熟练；生态最全 |
| 图鉴展示台 | **`<model-viewer>`**（Google 维护 Web Component） | 旋转/缩放/AR 一行集成，质量有保证——图鉴 3D 的成本护城河 |
| 主线 2D 元素/实验室模式 | PixiJS v8（实验室）/ DOM | 实验室沿用 v1.0 设计 |
| 图表/时间轴 | uPlot 或自绘 | 轻量 |
| 语音 | Web Speech API | 零成本 |
| 状态/存档 | 原生 + IndexedDB | 无账号，本地进度 |
| 测试 | Vitest + Playwright（含触控模拟） | 既有体系 |
| 部署 | GitHub Pages + CloudBase 备用；Service Worker 预缓存 | 断网可玩（答辩保险，本草宇宙验证过） |

**明确不用**：Unity/UE（与用户既有技能栈和 Web 目标不符；NCDA 的 UE 赛项不做——本作主投科普/VR 与游戏类不依赖 UE）、React（过重）、后端与账号（M4 前无）。

### 10.2 分层架构

```
┌───────────────────────────────────────────────┐
│ L4 内容与证据层 content/ evidence/             │
│  species.json · chapters · cards · 题库        │
│  validate:species 门禁 · CREDITS · 进度遥测     │
├───────────────────────────────────────────────┤
│ L3 模式层 modes/                               │
│  journey（主线）· codex（图鉴）· dig（挖掘）    │
│  quiz（挑战）· lab（实验室）· demo（演示）      │
├───────────────────────────────────────────────┤
│ L2 场景层 scene/                               │
│  场景装配 · 生物实例(动画状态机) · 相机标准件    │
│  热点系统 · 转场(大事件) · 光照/雾/粒子 · 音频   │
├───────────────────────────────────────────────┤
│ L1 基础层 core/                                │
│  资产加载(Draco/按需) · 进度存档 · 经济系统      │
│  TTS · 输入(鼠标/触控统一) · lab 仿真引擎        │
└───────────────────────────────────────────────┘
```

依赖单向 L4→L3→L2→L1；五个模式共享 L1/L2 标准件（相机、热点、浮层、经济），新增模式成本递减——这是"框架完整"的架构保证，也是 M5 扩展章节/模式的依托。

### 10.3 关键机制

- **资产按需加载**：按章节分包，进入章节才拉取该章模型（首屏只带第 1 章，< 3MB gzip）
- **生物实例**：场景生物 = GLTF + 动画状态机（idle/wander/flee/eat 四态起步）+ 热点挂点
- **大事件转场**：预烘焙关键帧相机动画 + 粒子（陨石/火山灰）+ 音频自动化——每章一个 10 秒高光，演示视频素材库
- **进度存档**：IndexedDB 本地；导出进度码（URL，可分享"我的图鉴完成度"）
- **离线**：SW 预缓存已解锁章节资产

### 10.4 性能预算

| 指标 | 目标 |
|---|---|
| 首屏可交互 | < 3 s（桌面）/ < 6 s（移动） |
| 帧率 | ≥ 60 fps 桌面 / ≥ 30 fps 移动 |
| 单场景面数 | < 150k 三角形（含生物） |
| 单模型 | ≤ 20k 面 / ≤ 2 MB（Draco 后） |
| 包体（不含模型） | < 3 MB gzip |

降级三档：粒子/阴影/抗锯齿关；生物实例数减半；移动端默认中档。

## 12. 里程碑（12 h/周，完整版约 205 h ≈ 17 周；20 h/周 ≈ 10 周）

### M0 · 3D 基石（25 h / 2 周）

技术栈搭建 + **模型处理管线打通**（找 3 个模型→许可核查→gltf-transform 处理→入库→model-viewer 展示台）+ 寒武纪场景灰盒（2 个动画生物 + 热点 + 相机）+ 移动端性能摸底。
**验收**：手机 30fps；展示台旋转/缩放/AR 一端真机通过；模型预算脚本就位。**红线 R1–R5 首轮演练。**

### M1 · 主线框架（45 h / 4 周）

## 13. 风险与对策

| 风险 | 概率 | 影响 | 对策 |
|---|---|---|---|
| 古生物 3D 模型找不齐（寒武纪奇特生物等） | **高** | 中 | 来源策略多通道（§6.3）；3D 覆盖率 ≥ 50% 即达标，其余高清复原图卡；自制占位 ≤ 25%；M0 即验证管线 |
| 模型许可污染（CC-BY 未署名等） | 中 | 高 | 逐模型许可登记 + CREDITS.md + validate 门禁含许可字段 |
| 3D 性能移动端不达标 | 中 | 中 | Draco+面数门禁+LOD+降级三档；M0 真机摸底前置 |
| **重蹈《一湖之年》覆辙：3D 做了但没被玩到** | 中 | **高** | §7 五条红线 + 每里程碑 3D 录屏验收 + E2E 断言 |
| 内容工作量大（48 物种 × 卡片+来源） | 高 | 中 | 分级交付（40 达标）；卡片模板化；来源以机构页为主（快）；M2/M4 分摊 |
| 变成"点击器"（学习感弱） | 中 | 高 | 经济设计：点数只来自学习动作（P1）；禁纯点击产出 |
| 范围蔓延 | 高 | 中 | 不做清单 + 裁剪表 |

### 不做清单（YAGNI）

多人在线 / 账号与云同步 / 生物捏造创造器 / 剧情对话树 / 多语言（预留）/ 原生 App / 手游化内购 / 全物种 3D（≥50% 即达标）/ UE 引擎重做 / 真实尺寸无限场景（用舞台化场景）。

### 表述边界

页脚声明：复原形象为科学理解的艺术呈现；知识卡标注来源级别；"人类世"等概念表述保持科学中性；不使用未经许可的博物馆实拍图（模型走开放获取数据）。

## 附录 A · 物种知识卡样例（1 张，体例定稿）

**奇虾（Anomalocaris）**
- 定义：寒武纪海洋中已知最大的捕食者之一，体长可达约 1 米，以一对前附肢捕食，是最早的顶级掠食者之一。
- 数据：年代 5.2–5.0 亿年前；体长 ~1 m；食性 肉食；分类 节肢动物（早期类群，分类位置有争议）
- 趣闻：它的嘴最初被误认为一只水母，前附肢被误认为虾——"奇虾"意为"奇特的虾"，其实谁也不是。
- 灭绝/去向：寒武纪末消失，无直接后裔类群延续至今。
- 来源：[B] Smithsonian NMNH 页面（url，核对 2026-10-25）；[C] IVPP 科普页（url）
- 模型：Sketchfab CC-BY（作者、url、Draco 后 1.4 MB、12k 面、动画 idle/swim）
- 解锁：第 2 章场景观察；稀有度：明星物种
