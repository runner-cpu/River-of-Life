## 3. 十个维度的证据

### 3.1 架构与可维护性

**ENG-ARCH-01，P2，已验证。** `mountLab` 在长期存在的 `#main-content` 上绑定匿名 `input` 监听器，退出页面只清除定时器、观察器和 visibility 监听，遗漏委托监听。再次进入后旧闭包仍持有旧比较区与状态。修复应限定在挂载清理契约，不需要更换 UI 框架。

现有的核心计算/视图分离、临时课堂存储、独立探究协议可继续沿用。大模块拆分是可选维护工作，不单凭行数认定缺陷。

### 3.2 正确性与健壮性

- **REL-COR-001，P2。** 两个真实 GameStore 实例共用存储时，A 观察并阅读蓝细菌，陈旧 B 观察叠层石，刷新后只剩 B 的观察、没有 A 的阅读。原因是只在 init 选择副本，之后每次动作覆盖完整快照。
- **REL-COR-002，P2。** 使用当前设置导入回调与可控制完成顺序的 File.text 复现：B 后选先完成，随后 A 仍覆盖 B；弹窗关闭/重置后，旧读取仍能恢复已重置的记录。
- **REL-COR-004，P2。** `+275760-09-13T00:00:00.000Z` 能通过旧验证，但递增后 Date 无效。import 已替换 state 才抛 RangeError，后续动作继续失败。
- **REL-COR-003，P2。** 与 ENG-REL-01 是同一缓存升级问题的另一后果，合并处理、不重复计数。

修复约束：不合并余额、不补发奖励、不改变 v1→v2 迁移契约；失败或过期导入必须保留上一份有效状态。

### 3.3 性能

**ENG-PERF-01，P2。** Texture.dispose 释放 GPU 纹理，不等于关闭 GLTFLoader 创建的 ImageBitmap。当前资源管理只计数 Texture，未对多个 Texture 共用的 bitmap 计算最终所有者。修复必须防止一个展台关闭时提前销毁另一展台还在用的图像。

**ENG-PERF-02，P2。** 离线准备使用固定 45 秒总超时，即使进度持续增加也会报失败。13 个 GLB 的实测文件大小为 11,989,972 bytes，独立 gzip level 6 为 7,519,346 bytes；按假设的 1 Mb/s 算，仅模型压缩字节传输就约需 60 秒。这是算术情景，不是真机测速。应使用无进展超时与有限总上限。

没有采集实体手机内存、帧率或耗电，因此不发布“提升百分比”。资源关闭测试证明生命周期行为，不直接证明节省多少内存。

### 3.4 3D 视觉与资产管线

**ENG-3D-01，P3，待视觉复核。** 异齿龙 GLB 含 JOINTS_1/WEIGHTS_1；9,955 个顶点中 505 个存在第二组非零权重，最大被忽略权重约 5.99%，平均约 0.0364%。当前渲染链只使用第一组四个影响。二进制兼容差异已复算，但尚未证明可见变形严重程度。

本轮保留资产，后续先对两段动画抽样和真机观看，再决定是否保留最强四权重并归一化。只删属性不能声称解剖质量改善。模型许可与来源元数据必须继续保留。

外部模型 13 个、明确结构示意 35 个的边界仍成立；原设计至少 24 个合格模型的目标尚未达到。

### 3.9 工程化与发布

- **ENG-REL-01（合并 REL-COR-003），P2。** A 页面保留旧哈希 lazy chunk 引用，B skipWaiting 后删除 A 缓存并接管；旧 chunk 可能已不在服务器，导致运行中的页面失败。完整离线模型也被删。应按浏览器默认 waiting 生命周期升级，并迁移“已准备离线”的能力而不是拷贝可能变更的同名旧字节。

### 6.1 存档与导入

实现提交为 `9af600a`、`150d407`、`f4d1d50`。单写者 Web Lock 在持久存储初始化前获取；其他窗口明确显示只读快照，支持临时切换已开启章节、临时答题和导出。关闭写入窗口后，其他窗口刷新才能取得写入权。没有 Web Locks 的环境保持只读。退出页面先撤销写入权限；恢复页面先重载。

文件导入在读取后再次检查请求序号、对话框状态和写入权限。关闭、重置、空选择、超限选择和原生文件取消都会让旧读取失效。文件读取失败保留原记录，同一文件可以重新选择。“重新开始”说明会保留损坏记录的恢复副本。

修订分配发生在账目变化之前。四位年时间采用同一个有界修订比较规则，避免极端时间跨过恢复边界后，成功写入的一份副本反而被旧副本覆盖。正常相邻历史时间保持先后关系和原始格式，启动不写副本；跨度达到约5000年时不承诺绝对民用时间顺序，规则有确定性。`updatedAt`同时承担本地修订排序，不是可信时间证明。没有新增存档字段、键或版本。

独立复核先发现只读交互、文件取消和日期边界问题，补修后再次复核通过。定向单元测试 **84/84**、TypeScript检查通过。主代理从 `3f507ab` 建立独立源码快照，内容/模型校验与生产构建通过；`npm run test:e2e -- tests/e2e/save-lifecycle.spec.ts` **8/8通过，22.9秒**。该快照仅验证第一组，不是最终发布构建。BFCache用例验证生命周期事件后的写入权限，不证明真实页面符合BFCache入栈条件。

### 6.2 离线版本与下载状态

实现提交为 `c3187f8`、`a07a93c`。新版遵循waiting生命周期，完整旧版存在时重新下载并校验全部新版资源；同路径的新模型不会混入旧版本。B先安装、A随后完成准备的场景，会在激活时保留完整A，并让打开的A、B页面在worker重启后仍读取各自的资源。线上返回成功但顺带缓存失败不再使响应失败；主动准备离线仍准确报错。
