# 生命长河实施记录

依据：`docs/design-spec.md`（用户授权执行，2026-10-25）。工作目录原为空，在本目录新建独立仓库和 feat/life-museum 分支。

## 任务与验收

1. 工程与内容：Vite / strict TypeScript / Three.js，八章、48条来源化知识卡、题库、门禁。
2. 3D资产与场景：来源及许可清单、模型实际预算检查、三个以上热点、轨道观察、动画、图鉴展台。
3. 学习循环：防重复奖励、章节任务和解锁、存档及导入导出、图鉴筛选、阅读/语音/体型比较。
4. 模式：挖掘、问答/排序/匹配/每日挑战、演示、实验室、课堂学习单与无障碍设置。
5. 验证：内容门禁、经济/存档/实验室单元测试、桌面与移动端浏览器流程、离线检查、构建。
6. 文档：启动方式、资产署名、AI使用记录、验收证据与尚需真实设备或人工完成的项目。

## 接口约定与实施决定

| 任务关系 | 共享接口 | 处理 |
| --- | --- | --- |
| 内容 → 模式 | `Species`, `Chapter`, `Question` | 定义在 src/core/types.ts，供所有模块使用 |
| 资产 → 场景/内容 | public/models/manifest.json | 逐模型记录实际物种、许可、来源、动画与预算；禁止把通用模型冒充其他物种 |
| 进度 → 所有模式 | GameStore | 所有奖励只能经唯一事件ID入账；奖励不来自定时器 |
| 3D → 旅程 | LifeScene(container, onSelect) | setChapter、focusSpecies、pause、dispose |
| 图鉴 → 内容 | 无来源不展示 | 内容与运行时双重校验 |

说明：方案章节年代是旧版时间标尺，采用合理近似并标注年代为约数；人类世作为讨论概念，不当作正式地质年代。
说明：AR组件可以集成和桌面检查，Android/iOS真机、完整课堂/60–90分钟使用研究、竞赛视频和软著申报不能伪称已验收。
说明：优先公开许可模型；取得不到合适模型的物种明确展示结构示意图卡及原因，不把示意模型计作博物馆模型。
