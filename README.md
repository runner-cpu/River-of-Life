# 生命长河 · River of Life

一个可在浏览器运行的生命演化史科普馆：沿八个纪元认识 48 个生命档案，通过三维观察、证据探究和对照实验练习解释。优先按科普教育／智慧教育作品准备，兼顾数字展陈与创新实践。

**在线体验：[https://runner-cpu.github.io/River-of-Life/](https://runner-cpu.github.io/River-of-Life/)**

源码仓库：[runner-cpu/River-of-Life](https://github.com/runner-cpu/River-of-Life)。直接在浏览器打开网站，无需安装、注册或启动本地服务。

**当前是已上线、可验证的科普教育原型，尚未达到原设计全部验收条件。** 已入库 13 个许可核验的外部三维模型，其余 35 个档案使用明确标注的原创结构示意。设计目标是至少 24 个合格模型；真实手机 AR、课堂用时研究与参赛成片尚待完成。详见 [交付状态](docs/delivery-status.md)。

## 启动

已在 Windows / Node.js 24.19.0 验证，建议使用 Node.js 24 LTS。

```sh
npm ci
npm run dev
```

打开终端打印的本地地址（通常为 `http://localhost:5173`；端口被占用时 Vite 会选择其他端口）。无需账户、API key 或后端。不要直接双击 `index.html`。

```sh
npm test                 # 存档、经济与实验室单元测试
npm run build           # 内容、模型、类型检查及生产构建
npx playwright install chromium
npm run test:e2e         # 使用独立测试浏览器验证生产版交互
npm run verify:build     # 记录当前构建哈希和文件预算
npm run package:competition # 完整测试通过后，生成独立展示准备包
npm run preview         # 预览 dist，通常为 http://localhost:4173
```

首次安装 Playwright 浏览器需要网络。生产内容与模型均随项目提供，运行不依赖 CDN；来源链接、操作系统语音和系统 AR 可另需网络。

## 怎么体验

教育展示可先走两条路线：

- 首页「3 分钟，做一次证据探究」：选始祖鸟、沧龙或提塔利克鱼，记录判断、观察查证、四类归类、查看关系反馈、解释新情境，最后导出可打印记录。支持文字路线；记录只在本次窗口保留，不自动评分自由文字，归类和解释不写入个人存档；个人成功导出满足条件时可记录零点行为徽章。
- 「演化实验室」下方「同一个起点，两个环境」：先预测，用相同初始种群与随机种子比较 0% 干旱和上方选定环境，查看 30 代曲线、逐代数据并导出 CSV。改变参数后需要重新运行，既有结果不会被悄悄改写。

15 分钟教学方案、3 分钟展示脚本和答辩材料见 [参赛准备](docs/competition/README.md)。活动时长、目标年龄与教师反馈框架尚待真实教学试测，软件测试不代表教学成效。

个人探索路线：

1. 在「演化之旅」点击生物热点或物种卡，打开可旋转展台。第一次发现会免费加入图鉴。
2. 阅读三张档案、观察三种生命、答对三道本章题，见证纪元事件，然后用 150 演化点开启下一章。
3. 从侧栏进入图鉴、化石挖掘、知识挑战或演化实验室。课堂模式可直接预览任何纪元、播放对应高光并导出学习单。
4. 「探索设置」可切换减少动效、投影大字和画面质量，也可导出／导入 JSON 存档。

同一观察、阅读、题目和挖掘只奖励一次。可选收藏会为尚未开启的下一纪元保留 150 点，避免收藏消费导致主线卡住。演示与课堂预览使用独立临时进度。

场景支持拖动、滚轮或双指缩放；键盘可使用热点按钮，场景画布支持左右方向键及 `+` / `-`。挖掘可刮擦，也有逐区清理按钮。`Esc` 关闭弹窗。

手机导航支持键盘焦点循环与 `Esc` 关闭；知识挑战页签支持方向键、`Home` 和 `End`。展台加载失败时会明确切换为原创结构示意，可以点击「重新加载原模型」重试。重新开始探索前会显示确认页，并提供记录备份入口。

八章均有约 10 秒独立三维高光，包括产氧、生命辐射、海洋缺氧、火山、撞击、草地和冰盖等抽象场景。可暂停、跳到总结和重温；减少动态时显示静态关键帧。声音只在开启环境音后播放。时间与形态为教学压缩，不是真实灾变模拟。

## 离线与存档

离线功能仅在 **生产构建** 中启用：运行 `npm run build`、`npm run preview`，打开「探索设置 → 准备离线展馆」，等待成功提示后再断网。首次成功访问会缓存应用代码与知识，完整准备会补齐模型。开发服务器不注册 Service Worker。

存档保存在当前站点的 IndexedDB，并以 localStorage 备份。不同浏览器、地址、协议或端口属于不同存档空间。更换设备或部署地址前请导出记录；导入会验证数据关系和奖励账目。浏览器清理站点数据会同时清除存档与缓存。

## 模型与内容

- 8 章，每章 6 个档案；144 道题与对应卡片字段关联。
- 四个 Quaternius CC0 动画模型：迷惑龙、剑龙、霸王龙、三角龙。
- 三个 Smithsonian CC0 扫描：始祖鸟化石板、猛犸骨架、巨齿鲨牙齿。扫描不会作为活体动物放入生态场景。
- 六个 CC BY 4.0 动画复原：奇虾、欧巴宾海蝎、怪诞虫、异齿龙、沧龙、水龙兽；保留原作者与衍生动画作者署名、许可和处理记录。
- 结构示意不计入开放模型数量，不代表经过专家确认的科学复原。颜色、运动、场景尺寸为艺术表达。
- 档案包含物种、属、较大类群和群落；章节汇集代表生命，不断言它们同地同时共存。
- 知识来源以已核对的 C 级百科为主，部分为 B 级博物馆机构；仍须专业人工复核。
- 三组探究补充博物馆／大学来源，并在档案显示具体核对范围；单个来源不为整张卡片的所有年代、尺寸或推断背书。

完整来源、许可和转换记录见 [CREDITS.md](CREDITS.md)，开发与功能中的 AI 使用见 [AI_USAGE.md](AI_USAGE.md)。

`model-viewer` 已接入 AR 能力，但需要兼容设备及 HTTPS。桌面显示成功不能替代 Android / iOS 真机验收，也不保证扫描资产的投放尺寸就是活体尺寸。

## 2026-11-12 本地交互增强

2026-11-12文档快照：线上旧基线于2026-10-30已发布，11月12日控制器复核首页HTTP 200、入口index-B7xP_END.js；本轮功能以本地acd3757为准；本说明检查时点未核验增强部署，后续部署结果以发布验证记录/Actions为准。

“纪元与档案关系”从现有章节与48档案派生年代范围，使用明确标注的压缩时间轴与等价分组列表；不是完整系统发生树，也不表示同地同时共存。小屏默认列表，可展开纪元并打开只读展台。此展台仍能旋转、缩放、查看来源、尺寸和结构标注，但不调用观察、阅读、收藏、比较记账或奖励，关闭后焦点回到原节点。完整内存Progress、updatedAt、localStorage与IndexedDB前后不变的检查已纳入回归。

本地新版探究路径为“初始判断→观察查证→四类归类→关系反馈→迁移问题→解释与记录”。每主题两张卡，可归为支持、无关、反对、需要更多信息；按钮与桌面拖放等价，全部卡片归类后显示只读SVG及等价文字列表。连线只呈现使用者对原始判断的归类，不判分、不推断能力。解释最多1200字符，返回修改可保留；关闭或刷新会丢失临时内容，应先导出。

HTML保留旧栏目并独立增加归类，旧依据单选显示“未记录”，不伪造答案或做一致性判断。JSON采用独立的`life-inquiry-record` v1协议，包含完整主题、原始与迁移选择、观察方式、卡片类别、来源及核对范围、解释；`answers.evidence`为null。它与Progress存档不是同一种文件，HTML不可当作JSON导入。

完成本人活动后，可在本地导入同一主题的完整同伴JSON，只读并列查看原始判断、归类、解释及共同来源范围，并阅读“具体差异”文本列表。不同只是记录不同，不代表谁正确。错误文件显示具体错误并保留当前内容；同伴原文按文本显示，不执行HTML，不合并本人答案，不写Progress、不授予徽章。文件选择限400000字节，解析限100000字符；验证类型、版本、完整阶段、UTC日期、选项、卡片及来源。离线可选本地文件；系统不提供上传、账号或云端同伴匹配。演示截图中的文字为讲解样例，不是真实学生或课堂研究数据。

对照实验增加四个10×10点阵，分别展示两组的初始与所选世代。取值1点数为round(频率×100)，其余为取值0；条纹1与上方耐旱表型一致。点位固定只是数量示意，不能追踪同一个体跨代生存。成功运行默认第30代，可用滑块、前后按钮和键盘选择0至30代；曲线标记、逐代表格当前行、频率和上一代百分点变化同步。第0代无上一代；更改种子、预测或环境会保留旧结果并提示重跑，重跑成功才重置世代。

始祖鸟、沧龙、提塔利克鱼各有三个默认关闭的结构观察点；其他档案显示无数据原因。扫描、复原与程序化示意使用各自的定位，沧龙动画使用随表面运动的锚点，示意点随相机投影；文字等价列表在无WebGL时仍可阅读。位置是近似教学观察点，未做科学解剖标定；看不清的扫描结构应查文字来源。第一次Esc关闭说明并回到触发点，第二次关闭展台。来源只支持具体登记范围，不认证整张卡片。

两枚新徽章只记录本机个人操作，均为零演化点，不代表科学能力。“保留判断”要求本次完成探究、至少一项“需要更多信息”归类并成功发起HTML或JSON下载；浏览器是否最终保留文件无法确认。“复现意识”要求本次活动已完成对照，再以不同种子实际运行完成，并明确为该次运行保存非空备注。仅改输入、同种子、空备注、旧运行备注不满足。备注绑定当前结果，重新运行、刷新或离开会丢失。课堂、演示、只读和同伴导入均不授予个人新徽章。

Progress数据版本升级为2，仍用localStorage键`life-museum-save-v1`与IndexedDB数据库`life-museum`、结构版本1、仓库`progress`、记录`current`。先校验v1再迁移，保留原updatedAt用于双副本择新，不追溯补发新徽章；v1中与新徽章保留ID碰巧重名的字符串不作为新奖。仅持久化徽章状态，解释、归类、同伴原文、实验备注仍为临时数据。非法导入不覆盖当前存档，拒绝未来版本；新版读取旧存档，不承诺旧网站读取v2。

实际代码验证：132/132单元（20文件）、69/69生产Chromium，build和verify:build通过；均对应acd3757。文档任务后的最终回归由控制器补充。详见[交互增强证据](evidence/interaction-enhancement.md)。
