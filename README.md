# 生命长河 · River of Life

一个可在浏览器运行的生命演化史科普馆：沿八个纪元认识 48 个生命档案，通过三维观察、证据探究和对照实验练习解释。优先按科普教育／智慧教育作品准备，兼顾数字展陈与创新实践。

**当前是可运行、可验证的本地原型，尚未达到原设计全部验收条件。** 已入库 13 个许可核验的外部三维模型，其余 35 个档案使用明确标注的原创结构示意。设计目标是至少 24 个合格模型；真实手机 AR、课堂用时研究与参赛成片尚待完成。详见 [交付状态](docs/delivery-status.md)。

## 启动

已在 Windows / Node.js 24.19.0 验证，建议使用 Node.js 24 LTS。

```sh
npm ci
npm run dev
```

打开终端打印的本地地址（通常为 `http://localhost:5173`；端口被占用时 Vite 会选择其他端口）。无需账户、API key 或后端。不要直接双击 `index.html`。

```sh
npm test                 # 存档、经济与实验室单元测试
npm run build           # 内容、模型、类型检查及生产构建
npx playwright install chromium
npm run test:e2e         # 使用独立测试浏览器验证生产版交互
npm run verify:build     # 记录当前构建哈希和文件预算
npm run package:competition # 完整测试通过后，生成独立展示准备包
npm run preview         # 预览 dist，通常为 http://localhost:4173
```

首次安装 Playwright 浏览器需要网络。生产内容与模型均随项目提供，运行不依赖 CDN；来源链接、操作系统语音和系统 AR 可另需网络。

## 怎么体验

教育展示可先走两条路线：

- 首页「3 分钟，做一次证据探究」：选始祖鸟、沧龙或提塔利克鱼，记录判断、观察查证、选择证据、解释新情境，最后导出可打印记录。支持文字路线；记录只在本次窗口保留，不自动评分自由文字，也不改变个人图鉴。
- 「演化实验室」下方「同一个起点，两个环境」：先预测，用相同初始种群与随机种子比较 0% 干旱和上方选定环境，查看 30 代曲线、逐代数据并导出 CSV。改变参数后需要重新运行，既有结果不会被悄悄改写。

15 分钟教学方案、3 分钟展示脚本和答辩材料见 [参赛准备](docs/competition/README.md)。活动时长、目标年龄与教师反馈框架尚待真实教学试测，软件测试不代表教学成效。

个人探索路线：

1. 在「演化之旅」点击生物热点或物种卡，打开可旋转展台。第一次发现会免费加入图鉴。
2. 阅读三张档案、观察三种生命、答对三道本章题，见证纪元事件，然后用 150 演化点开启下一章。
3. 从侧栏进入图鉴、化石挖掘、知识挑战或演化实验室。课堂模式可直接预览任何纪元、播放对应高光并导出学习单。
4. 「探索设置」可切换减少动效、投影大字和画面质量，也可导出／导入 JSON 存档。

同一观察、阅读、题目和挖掘只奖励一次。可选收藏会为尚未开启的下一纪元保留 150 点，避免收藏消费导致主线卡住。演示与课堂预览使用独立临时进度。

场景支持拖动、滚轮或双指缩放；键盘可使用热点按钮，场景画布支持左右方向键及 `+` / `-`。挖掘可刮擦，也有逐区清理按钮。`Esc` 关闭弹窗。

手机导航支持键盘焦点循环与 `Esc` 关闭；知识挑战页签支持方向键、`Home` 和 `End`。展台加载失败时会明确切换为原创结构示意，可以点击「重新加载原模型」重试。重新开始探索前会显示确认页，并提供记录备份入口。

八章均有约 10 秒独立三维高光，包括产氧、生命辐射、海洋缺氧、火山、撞击、草地和冰盖等抽象场景。可暂停、跳到总结和重温；减少动态时显示静态关键帧。声音只在开启环境音后播放。时间与形态为教学压缩，不是真实灾变模拟。

## 离线与存档

离线功能仅在 **生产构建** 中启用：运行 `npm run build`、`npm run preview`，打开「探索设置 → 准备离线展馆」，等待成功提示后再断网。首次成功访问会缓存应用代码与知识，完整准备会补齐模型。开发服务器不注册 Service Worker。

存档保存在当前站点的 IndexedDB，并以 localStorage 备份。不同浏览器、地址、协议或端口属于不同存档空间。更换设备或部署地址前请导出记录；导入会验证数据关系和奖励账目。浏览器清理站点数据会同时清除存档与缓存。

## 模型与内容

- 8 章，每章 6 个档案；144 道题与对应卡片字段关联。
- 四个 Quaternius CC0 动画模型：迷惑龙、剑龙、霸王龙、三角龙。
- 三个 Smithsonian CC0 扫描：始祖鸟化石板、猛犸骨架、巨齿鲨牙齿。扫描不会作为活体动物放入生态场景。
- 六个 CC BY 4.0 动画复原：奇虾、欧巴宾海蝎、怪诞虫、异齿龙、沧龙、水龙兽；保留原作者与衍生动画作者署名、许可和处理记录。
- 结构示意不计入开放模型数量，不代表经过专家确认的科学复原。颜色、运动、场景尺寸为艺术表达。
- 档案包含物种、属、较大类群和群落；章节汇集代表生命，不断言它们同地同时共存。
- 知识来源以已核对的 C 级百科为主，部分为 B 级博物馆机构；仍须专业人工复核。
- 三组探究补充博物馆／大学来源，并在档案显示具体核对范围；单个来源不为整张卡片的所有年代、尺寸或推断背书。

完整来源、许可和转换记录见 [CREDITS.md](CREDITS.md)，开发与功能中的 AI 使用见 [AI_USAGE.md](AI_USAGE.md)。

`model-viewer` 已接入 AR 能力，但需要兼容设备及 HTTPS。桌面显示成功不能替代 Android / iOS 真机验收，也不保证扫描资产的投放尺寸就是活体尺寸。

## 工程结构

| 路径 | 用途 |
| --- | --- |
| `src/content/` | 章节、生命档案、题库 |
| `src/core/` | 类型、存档与经济、教学实验模型、公共交互 |
| `src/scene/` | Three.js 场景、可交互展台、原创结构示意 |
| `src/modes/` | 图鉴卡片、挖掘、挑战、实验室与本地导览 |
| `public/models/` | 发布模型、许可文本与 manifest |
| `scripts/validate-*.ts` | 内容来源与模型预算门禁 |
| `tests/` | 单元与浏览器测试 |
| `evidence/` | 内容、模型、测试和代码复核记录 |
| `docs/competition/` | 作品介绍、教学方案、展示脚本、提交缺口 |
| `output/competition/` | 忽略入库的独立展示包，含站点、可打印说明与验证材料 |
